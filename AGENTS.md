# AGENTS.md

Instructions for AI agents (including Claude Code) working in this repository.

## This repository

A web app that generates mock questions for AWS certification exams. Questions and
explanations are dynamically generated by a generative AI and the app runs on AWS.
Read `README.md` first for the overall picture (personal design notes live in the
git-ignored `docs_local/`).

## Directories

- `apps/web` … frontend (Vite+React+TS, not started yet)
- `apps/api` … business logic API (Hono + Lambda Web Adapter, TS)
- `apps/agent` … question generation agent (Strands + Bedrock, Python)
- `packages/shared` … TS types and DynamoDB table definitions shared between
  web and api (`@aws-mon/shared`)
- `infra` … Terraform (envs = local / prod)
- `local` … local dev environment (DynamoDB Local + LocalStack; `local/seed` has
  the seed data scripts)
- `docs` … design docs, ADRs, research notes

The root is npm workspaces (`packages/*` and `apps/api`). `apps/api` depends on
`packages/shared`'s build output (`dist/`), so build shared first after touching
its dependencies.

## Common commands

```bash
# Install deps + build the shared package (first run, or after changing shared)
npm install
npm run build -w @aws-mon/shared

# Local infra
cd local && docker compose up -d

# Create tables in local DynamoDB + seed data
cd infra/envs/local && terraform init && terraform apply
cd local/seed && npm install && npm run seed

# API
cd apps/api && npm run dev      # http://localhost:8080/health
npm run typecheck --workspaces --if-present   # type check (from repo root)

# Question generation agent (requires AWS auth + Bedrock model access)
cd apps/agent && python -m quiz_agent.cli --cert aip
```

## Security constraints (must follow)

- **Monitoring AI must only use readonly AWS roles/credentials.** Never grant write access.
- **PR automation must only react to issues created by myself (the repo owner).** Never
  act on issues from anyone else.
- **Never expose Bedrock (or other) credentials client-side or in commits** (cloud = IAM
  role, local = `.env` / local credentials; never commit `.env`).
- Never run destructive or irreversible operations (deletions, force push, prod deploys)
  without confirmation.

## Code policy

- The original prototype `aws-quiz-v2.tsx` is a **reference for functionality/UX only**.
  Don't reuse its code or design — rebuild from scratch.
- Redesign the frontend with the `frontend-design` skill; **avoid generic
  AI-looking boilerplate design**.
- The API (TS) assumes LWA — don't write Lambda-specific code; write it as a plain
  web server.
- The agent (Python) uses structured output (Pydantic) — don't parse JSON out of text.
